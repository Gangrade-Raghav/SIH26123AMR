# Definition of Done

A milestone cannot be declared complete merely because the code compiles.

## Required

### Code
- implementation is coherent,
- interfaces are documented,
- configuration is externalized.

### Tests
- unit tests pass,
- integration tests pass where applicable,
- regression tests pass.

### Simulation
- reproducible smoke test succeeds.

### Observability
- meaningful metrics exist,
- failures are visible in logs/state.

### Documentation
- architecture updated,
- assumptions recorded,
- known limitations recorded.

### Reproducibility
- run command documented,
- configuration saved,
- seed recorded if applicable.

### Git
- clean or intentionally modified working tree,
- changes are reviewable.

## Scientific requirement

A measured result must never be presented as a general guarantee.

Every claim should identify:
- conditions,
- scale,
- workload,
- map,
- hardware,
- software revision.
