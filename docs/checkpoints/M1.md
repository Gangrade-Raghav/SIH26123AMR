## 5. Simulation Evidence

The automated test script [`scripts/verify_m1_simulation.py`](file:///home/raghav/Downloads/NRDAS_Antigravity_Project_Starter/antigravity_amr_project/scripts/verify_m1_simulation.py) is the dedicated integration test that executes the physical simulation stack.

### Subsystem Verification Actions
1. **Launch Gazebo**: Spawns `gz sim server` (`gz-sim 8.11.0`) with `warehouse_small.sdf` in headless mode (`-s -r`), stepping physics with the DART engine (0.005s step size).
2. **Spawn the AMR**: Executes `ros_gz_sim create` node which parses `amr_0/robot_description` and dynamically injects entity `amr_0` into the running Gazebo world.
3. **Publish `/cmd_vel`**: Instantiates a ROS 2 publisher on `/amr_0/cmd_vel` transmitting `geometry_msgs/msg/Twist` at 10Hz, bridged to Gazebo's DiffDrive system.
4. **Verify Motion**: Samples initial pose from `/amr_0/odom`, commands forward velocity, samples subsequent poses, and measures physical displacement along the X axis.
5. **Verify Odometry**: Subscribes to `/amr_0/odom` (`nav_msgs/msg/Odometry`), asserting message reception, header timestamp progression, and frame IDs (`amr_0/odom` -> `amr_0/base_footprint`).
6. **Verify LiDAR**: Subscribes to `/amr_0/scan` (`sensor_msgs/msg/LaserScan`), asserting ray count (360 samples) and valid ranges reflected from warehouse walls.
7. **Verify TF**: Subscribes to `/tf` and `/tf_static` with `transient_local` QoS, asserting active parent-child relationships across the complete kinematic tree.
8. **Verify Clean Shutdown**: Transmits `SIGINT` to the simulation process group, confirms orderly node teardown within 8 seconds, and performs process isolation sweeps (`pkill -9 -f "gz sim"`).

- **Commanded Linear Velocity ($v_x$)**: `0.50 m/s`
- **Commanded Angular Velocity ($\omega_z$)**: `0.00 rad/s`
- **Command Duration**: `2.50 s`
- **Theoretical Displacement (Kinematic)**: $s = v \times t = 0.50 \times 2.50 = 1.250\text{ m}$
- **Theoretical Displacement (Dynamic with Acceleration Limits)**:
  - Max acceleration limit: $a_{max} = 2.0\text{ m/s}^2$
  - Acceleration ramp duration: $t_{acc} = 0.50 / 2.0 = 0.25\text{ s}$
  - Displacement during acceleration: $\frac{1}{2} a t_{acc}^2 = 0.0625\text{ m}$
  - Constant speed duration: $t_{const} = 2.50 - 0.25 = 2.25\text{ s}$, displacement: $0.50 \times 2.25 = 1.125\text{ m}$

- **Stop Behavior**: Upon publishing `/cmd_vel = [0.0, 0.0]`, the DiffDrive system decelerated to 0.0 m/s. The robot maintained a stable stationary pose at $X = 1.260\text{ m}$ for 1.5 seconds with zero drift.

## 13. Known Limitations

The following items are outside the scope of Milestone M1 and were **not** validated:

1. **Multi-Robot Physics Interactions**: Only a single AMR (`amr_0`) was spawned and tested. Dynamic physical collisions between multiple robots and inter-robot communications are deferred to M2.
2. **Dynamic Obstacles**: The simulation world contains static walls and warehouse storage racks. Moving obstacles or human agents were not tested.
3. **Nav2 Navigation Stack Integration**: The Nav2 navigation stack (costmap generation, global path planning, local trajectory following) was not wired to the AMR in M1. Only raw `/cmd_vel` control and `/odom` telemetry were validated.
4. **Terrain Non-Uniformity**: The simulation assumes a planar, frictionless ground model with flat terrain. Ramps, inclines, or irregular surfaces were not evaluated.
5. **Hardware-in-the-Loop**: All validation was conducted in Gazebo Harmonic simulation on an Intel Core i7 CPU with integrated graphics; physical hardware deployment was not tested.
